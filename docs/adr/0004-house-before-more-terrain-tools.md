# ADR 0004: House massing (M5) before the remaining terrain tools (M4b–M4d)

Date: 2026-11-08 · Status: accepted (user, 2026-11-08)

## Context
PLAN.md ordered M4a → M4b → M4c → M4d → M5. After M4a T1 the user noted that the Environment viewport has no house,
and that more terrain tools are of little use without it: levels, slopes and walls are judged against the house.

## Decision
- Finish M4a as planned (T2–T4).
- Then **M5 (house massing)**, then M4b → M4c → M4d.
- M5's spec gets sharpened on the real files when it starts (`spec-driven-development`), like the earlier milestones.

## Consequences
- M4b's ✅ (terrace at +0.30 next to the house with a 1:2 slope) can be checked against a real façade.
- M4b–M4d are unchanged in content, only later.
